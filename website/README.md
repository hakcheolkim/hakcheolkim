# 김학철 홈페이지

전직지원전문가 김학철의 소개, 경력, 자격, 강의 분야 및 실적을 담은 정적 홈페이지입니다.

## 사이트

https://hakcheol-career.imkhch.chatgpt.site

현재 소유자 확인용 비공개 상태입니다. www.hakcheol.com은 DNS 설정을 기다리고 있습니다.

## 수정

- index.html: 소개, 경력, 강의 실적, 연락처
- styles.css: 화면 디자인 및 모바일 대응
- script.js: 이메일 문의 작성
- assets/kim-hakcheol.png: 제공받은 프로필 사진

강의 문의는 방문자의 이메일 앱을 열어 내용을 전달합니다. 자동 발송이나 서버 저장 기능은 없습니다.

이 저장소는 홈페이지 소스 보관용입니다. GitHub 변경 사항의 Sites 자동 배포는 설정되어 있지 않으며, 수정 후 별도 배포가 필요합니다.

경력과 자격, 강의 실적은 제공받은 강사 프로필을 기준으로 작성했습니다. 원본 PPTX는 포함하지 않았습니다.
